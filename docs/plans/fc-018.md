## Context

FC-015 shipped 2026-05-12 — narration text is now rendered as a Skia paragraph inside the page-curl Group instead of baked into the illustration. To guarantee legibility on busy backgrounds, the implementation paints a translucent rounded rect behind every paragraph: `palette.colors.cardBg` (= `#FFFFFF` in every palette) at 86% alpha.

User feedback after live testing (2026-05-16): **the white box is too prominent, blocks too much of the illustration, and reads as a label slapped on top rather than typography integrated into the page**. They want the Dr. Seuss / Pout-Pout Fish feel: text that's part of the composition, not a UI panel.

The constraint is real: dropping the rect entirely puts 100% of the legibility burden on (a) Gemini actually reserving clean low-detail negative space at the chosen `textPosition` and (b) text styling alone. Anecdotal evidence says Gemini fails (a) on ~10-20% of pages. We need an approach that looks integrated *and* fails gracefully when the illustration is busier than reserved.

## Goals

- Remove the always-on opaque white rectangle behind narration text.
- Make text feel typographically rich and composed-into-the-page (Dr. Seuss / Pout-Pout vibe), via multi-shadow text styling that adapts to most backgrounds.
- Keep a graceful-degradation safety net for the worst-case position (`center-overlay`, which sits over the focal subject by definition) using a soft *radial* halo (not a hard rect).
- Tighten the illustration prompt's negative-space contract with explicit negative constraints so Gemini stops painting literal white rectangles when it interprets "reserve space" wrong.
- Zero new dependencies. Pure code change to the Skia text fragment + prompt copy + palette.

## Non-goals

- No glyph stroke / 4-pass text rendering. Skia has no native stroke API; the workaround (rendering text 4 times at small offsets to simulate an outline) is 5× the per-frame cost on the curl-shader hot path and the visual win at 26-48dp is marginal vs. just bumping weight + tightening shadows. Hold for a future "title typography" effort.
- No image-content sampling to dynamically pick text color per page. Real fix to per-page contrast, but a project of its own (sampling timing vs. image load, perf, edge cases).
- No new asset work (hand-drawn torn-paper SVG sticker backings would be the most authentic Pout-Pout treatment but require per-palette/style assets).
- No backend pipeline changes beyond prompt copy. The data contract (`textPosition`, `soundEffects`, `emphasizedWords`) stays unchanged.

## Proposed approach

### 1. PageTextLayer.tsx — gut the rect, add a multi-shadow text stack, add a per-position halo for `center-overlay`

**Remove:** the `<RoundedRect>` from the JSX (`PageTextLayer.tsx:168-175`) and its dimension calc except where the `center-overlay` halo branch needs it.

**Add to `baseTextStyle.shadows`** (and a slightly heavier variant on `emphTextStyle.shadows`). Order in the array matters — Skia paints shadows in array order, all behind the glyph, so widest goes FIRST:

```ts
shadows: [
  // (1) Warm halo — load-bearing legibility helper. Replaces the rect.
  //     Uses palette haloColor (a warm cream/tint, never pure white).
  { color: Skia.Color(haloColor + 'B3'), offset: { x: 0, y: 0 }, blurRadius: 16 },
  // (2) Soft drop shadow — gives the text "lift" off the page.
  { color: Skia.Color('#00000088'),       offset: { x: 0, y: 2 }, blurRadius: 5 },
  // (3) Tight near-glyph shadow — adds visual weight, fakes a subtle outline.
  { color: Skia.Color('#00000066'),       offset: { x: 0, y: 1 }, blurRadius: 2 },
]
```

Tuning notes (per Plan-agent feedback): blur 8 in v1 was too tight for 26-48dp text; bumped to 14-18. Cap at 3 shadows (4+ has measurable jank on the curl shader's offscreen layer on older Android). Don't add a 1px-blur fake-stroke shadow — Skia text shadow is Gaussian, single-direction 1px just looks fuzzy.

**Font weight:** bump `baseTextStyle.fontStyle.weight` from default (400) to **700**; `emphTextStyle.weight` from 700 to **800**. Picture-book typography is consistently heavy.

**`center-overlay` halo branch** (the only position that sits over the focal subject by design):

```tsx
{page.textPosition === 'center-overlay' && (
  <Group>
    <Rect x={haloX} y={haloY} width={haloW} height={haloH}>
      <Paint>
        <RadialGradient
          c={{ x: haloX + haloW/2, y: haloY + haloH/2 }}
          r={Math.max(haloW, haloH) / 2}
          colors={[Skia.Color(haloColor + '8C'), Skia.Color(haloColor + '00')]}
          positions={[0, 1]}
        />
      </Paint>
    </Rect>
  </Group>
)}
```

Sized to ≈1.4× the paragraph dimensions so the soft fade extends past text edges. Gradient alpha ramp (0.55 center → 0 edge) replaces the hard-edged rect with a "page got misty here" feel.

### 2. ColorPalettes.ts — add `haloColor` per palette

The current backing pulls from `cardBg` (= `#FFFFFF` everywhere). Pure white halos look like "label residue" against warm illustration palettes. Add a new `haloColor: string` field to `ColorPalette["colors"]`. Each palette gets a warm derivative of its `background` color family, NOT cardBg.

### 3. Curl.tsx + read.tsx — rename `backingColor` prop → `haloColor`

Clean prop rename across the wiring (Curl.tsx: prop type, destructure, default, JSX pass-throughs). In `read.tsx`, replace `backingColor={`${palette.colors.cardBg}D9`}` with `haloColor={palette.colors.haloColor}` (no alpha math in the caller — the gradient/shadows internally control alpha).

### 4. illustration.ts — strengthen negative-space contract with explicit NEGATIVES

The current `TEXT_POSITION_RESERVATION` entries ask for "low-detail negative space" — soft language. Gemini still occasionally paints a literal white rectangle. Tighten each entry with:

- An explicit organic-zone example ("treat the top 22% as open sky, with no characters, no clouds, no birds")
- An explicit NEGATIVE: "DO NOT paint a literal white box, panel, banner, or rectangular card. The reservation is a *compositional choice* (open sky, calm water, soft wash), NOT a *graphic element*. No solid color blocks."
- A "low contrast variation, blurred not detailed" cue

Pure prompt copy. No function signature change.

## Risks & mitigations

- **Risk:** removing the rect exposes glyph edges to the page-curl shader's deformation. Mid-curl, edges may shimmer.
  - **Mitigation:** visual smoke-test mid-swipe; if shimmer is bad, expand the halo (currently center-overlay only) to other positions as a smaller-blur safety net.
- **Risk:** Skia text shadow renderer's blur is Gaussian — too many shadows = perf hit on the curl-shader hot path. **Mitigation:** capped at 3 shadows.
- **Risk:** legibility on extreme cases (dense dark illustration + light text). **Mitigation:** shadow stack handles 80-90% of cases; `center-overlay` halo handles the worst position. Iterate halo color/scope post-ship if needed.
- **Risk:** illustration prompt change may not stop Gemini from painting white rectangles. **Mitigation:** if visual regen still shows literal boxes, add a few-shot bad-example block to the prompt.
- **Risk:** font-weight 700 baseline might feel too heavy for "Gentle Refrains" voice. **Mitigation:** uniform weight in v1; conditionalize on writingStyle in a follow-up if needed.
