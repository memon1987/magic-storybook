## Context

In the story reader, tapping is overloaded: it both toggles the info bars (title/close + page dots/counter) and navigates via hard-coded zones — left 25% = previous, right 25% = next, center 50% = toggle. So a tap meant to reveal the bars frequently lands in an edge zone and **accidentally flips the page** (reported on build 11 / FC-026, which otherwise renders well).

**Decisions locked with the user:**
1. **Decouple tap from navigation** — a tap *anywhere* only toggles the controls bars; tap never navigates.
2. **Add a backward page-curl swipe** — the curl was forward-only; add a left-to-right drag that curls the **previous** page back on and commits to `currentPage - 1`.

Forward navigation (swipe-left curl) is unchanged; the dots remain a jump-to-any-page affordance.

## Key findings (validated)

- **The existing GLSL shader (`pageCurl.ts`) is reusable for backward — no rewrite.** Feeding the curl-layer top = previous image with `origin` held at `width` and `pointer` animated `0 → width` makes the fold `x = width - (origin - pointer)` sweep **left → right**, so the previous page fills in **from the left edge**. No mirror variant.
- **`usePageImages` already returns `{ prev, current, next }`** with `prev` gated (page 0 → null; FC-022 empty-URL synthetic end page → null). No hook change — read.tsx just forwards `pageImages.prev`.

## Approach

### Curl.tsx (primary)
- **Tap decouple:** `Gesture.Tap().maxDistance(8).onEnd(() => runOnJS(onTap)())`; `onTap` prop becomes `() => void`; remove the `TapZone` type.
- **Direction state machine:** `direction` React state (`'forward'|'backward'`) + worklet-readable `isBackward` shared value. Decided once at pan `onStart` from `sign(e.translationX)`. Gestures are memoized (deps exclude `direction`) so the mid-swipe `setDirection` re-render can't drop the in-flight pan.
  - Forward: `origin = e.x`, `pointer = max(0, min(origin, e.x))`; commit if `(origin-pointer)/width > 0.25 && currentPage < totalPages-1` → `withTiming(pointer→0)` then `onPageChange(currentPage+1)`; else spring to `origin`.
  - Backward: `origin = width`, `pointer = clamp(translationX, 0, width)`; commit if `pointer/width > 0.25 && currentPage > 0` → `withTiming(pointer→width)`, reset `isBackward=false`, then `onPageChange(currentPage-1)`; else `withSpring(pointer→0)`, reset `isBackward=false`, collapse to identity (`origin=pointer`) + `setDirection('forward')`.
- **Render swap:** `curlImage = backward ? previousImage : currentImage` (shader layer); `revealImage = backward ? currentImage : nextImage` (sharp contain beneath, opacity-gated). `revealOpacity` = forward `pointer < origin ? 1 : 0`; backward `0 < pointer < width ? 1 : 0` (transition-only gate avoids next-page bleed through the contain margins at rest). Ambient backdrop stays keyed to `currentImage`.
- **Reset:** `useLayoutEffect` on `[currentPage, width]` resets `origin = pointer = width`, `isBackward = false`, `direction = 'forward'`.

### read.tsx
- Drop `type TapZone` import; `handleTap = () => setControlsVisible(v => !v)`; pass `previousImage={pageImages.prev}`. `handlePageChange` already handles backward (`currentPage-1`, can be 0).
