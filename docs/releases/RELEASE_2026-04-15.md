## Key Decisions & Rationale

### Cloud Build over GitHub Actions
Chose Google Cloud Build (Option A) over GitHub Actions because the backend is already on GCP. Fewer moving parts — no need to store GCP credentials in GitHub Secrets. Native integration with Artifact Registry and Cloud Run.

### Stay on `gemini-3-pro-image-preview` for image generation
Evaluated Imagen 4 ($0.02-0.06/image) and `gemini-3.1-flash-image-preview` ($0.045/image) as cheaper alternatives. Staying on Gemini 3 Pro ($0.13/image) because text-in-image accuracy (94-96%) is non-negotiable for the Dr. Seuss style embedded text. Imagen 4 has lower text accuracy. Recommend benchmarking `gemini-3.1-flash-image-preview` later for cost savings (FC-002).

### Expo Go for interim testing over Apple Developer Account
Recommended Expo Go as a zero-cost path to test on iPhone immediately while waiting for Apple Developer Account approval ($99/year, up to 48hrs). User chose to proceed with the full Apple Developer path anyway.

### Plan-first development from `options_wheel-1`
Adopted the same FC lifecycle and plan file structure from the user's options_wheel repo. Ensures traceability: FC entry → plan file → commit/PR. One PR per FC for clean rollback.

### Frontend redesign as clean rewrite, not incremental migration
User explicitly requested removing old/redundant code and starting clean rather than patching. Plan (fc-001.md) specifies deleting `Colors.ts`, `Typography.ts`, `preview.tsx` and fully rewriting every screen file.
